# Quiz Project

## 1. Жоба туралы

Quiz Project — Python бағдарламалау тілінде жасалған қарапайым викторина бағдарламасы. Бағдарлама пайдаланушыға түрлі сұрақтар қойып, жауаптарын тексеруге және соңында жинаған ұпайын көруге мүмкіндік береді.

## 2. Жобаның мақсаты

Жобаның мақсаты — пайдаланушылардың білімін тексеруге арналған викторина бағдарламасын әзірлеу және Python тіліндегі негізгі бағдарламалау дағдыларын тәжірибе жүзінде қолдану.

## 3. Кімге арналған?

Бұл бағдарлама:
- Python тілін үйреніп жүрген студенттерге;
- Өз білімін тексергісі келетін пайдаланушыларға;
- Викторина арқылы білімін жетілдіргісі келетін адамдарға арналған.

## 4. Бағдарламаның мүмкіндіктері

- Пайдаланушыға 5 сұрақ ұсынады.
- Әр сұраққа 4 жауап нұсқасын көрсетеді.
- Пайдаланушының жауабын қабылдайды.
- Дұрыс және қате жауаптарды тексереді.
- Дұрыс жауаптардың санын есептейді.
- Соңында жалпы ұпай мен пайыздық нәтижені көрсетеді.
- Қате енгізілген мәліметтерді тексереді.

## 5. Қолданылған технологиялар

- Python 3 — бағдарламалау тілі.
- Git — жобаның өзгерістер тарихын бақылау.
- GitHub — жобаны сақтау және жариялау платформасы.

## 6. Жобаға қойылатын талаптар

Бағдарламаны іске қосу үшін:
- Python 3 орнатылған болуы керек.
- Компьютерде терминал немесе командалық жол болуы керек.
- Жоба файлдары жүктелген болуы керек.

## 7. Орнату жолы

1. GitHub репозиторийіне өту.
2. Code батырмасын басу.
3. Copy URL арқылы сілтемені көшіру.
4. Терминалды ашу.
5. Жобаны компьютерге жүктеу:

```bash
git clone https://github.com/Dastan7277/Quiz_Project.git
```

6. Жоба бумасына кіру:

```bash
cd Quiz_Project
```

## 8. Бағдарламаны іске қосу

Терминалда келесі команданы енгізіңіз:

```bash
py main.py
```

Осыдан кейін викторина бағдарламасы іске қосылады.

## 9. Пайдалану нұсқаулығы

1. Бағдарламаны іске қосыңыз.
2. Экранда көрсетілген сұрақты оқыңыз.
3. Төрт жауап нұсқасының бірін таңдаңыз.
4. Жауап нөмірін енгізіңіз (1-ден 4-ке дейін).
5. Барлық сұрақтарға жауап беріңіз.
6. Соңында жинаған ұпайыңыз бен нәтижеңіз көрсетіледі.

## 10. Қателерді өңдеу

Бағдарлама пайдаланушы енгізген жауаптарды тексереді.

- Егер пайдаланушы санның орнына әріп енгізсе, бағдарлама қате туралы хабарлайды.
- Егер 1-ден 4-ке дейінгі аралықтан тыс сан енгізілсе, қайта енгізу сұралады.
- Дұрыс жауап таңдалса, ұпай қосылады.
- Қате жауап таңдалса, ұпай қосылмайды.

## 11. Тестілеу

Бағдарлама келесі жағдайлар бойынша тексеріледі:

- Дұрыс жауап енгізу.
- Қате жауап енгізу.
- Әріп енгізу.
- 1-ден 4-ке дейінгі аралықтан тыс сан енгізу.
- Қорытынды ұпайдың дұрыс есептелуі.
