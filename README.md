# Викторина для проверки знаний

## Описание

Консольная программа на Python для проверки знаний пользователя.

## Возможности

- вывод вопросов;
- четыре варианта ответа;
- проверка ответа;
- подсчёт баллов;
- процент правильных ответов;
- обработка ошибок ввода.

## Технологии

- Python 3
- Git
- GitHub

## Запуск

```bash
python main.py
```

## Тестирование

Проверено:

- правильные ответы;
- неправильные ответы;
- ввод букв;
- ввод чисел вне диапазона.
